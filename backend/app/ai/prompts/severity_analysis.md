# Severity & Impact Assessment

Given a confirmed finding's category, affected asset, and evidence
below, assess severity using CVSS-style reasoning (attack vector,
complexity, privileges required, user interaction, scope, and impact on
confidentiality/integrity/availability).

Map the result to an OWASP Top 10 category and a CWE ID where
applicable, and briefly justify the severity level chosen in
reasoning_summary — do not just state a label.
